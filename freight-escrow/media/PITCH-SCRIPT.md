# Founder pitch script — about 90 seconds

Record this in your own voice. Introduce yourself using the name you want judges to see. Confirm the freight experience below is accurate before recording. Do not describe the project as deployed, audited or used by customers.

Hi, I’m the founder of FOKS Freight Escrow. I work in freight logistics and dispatch, including Amazon Relay, and I build tools for carrier operations.

Our idea is simple: reserve payment before a load starts, then release it after delivery approval. We are building for shippers and carriers who already agree to settle using stablecoins.

The shipper funds an escrow and names the carrier and an arbitrator in advance. The carrier accepts the load. After delivery review, the shipper approves payment. If there is a dispute, payment pauses and the agreed arbitrator allocates the funds. If nobody accepts before the deadline, the shipper can reclaim the payment.

Solana records funds and settlement. It does not prove that a truck delivered a shipment. Delivery documents stay off-chain, and the approval and arbitration process must be designed carefully.

Today we have an Anchor contract draft, a runnable reference model, eight passing model tests and a successful Rust host compilation check. We have not deployed or audited the program. We used substantial AI assistance and still need validator tests, a wallet client and a devnet demonstration.

CertiK credits would help us review the code that will eventually control user funds. Our next goal is a verified devnet workflow and an independent audit before a limited mainnet pilot. My freight experience helps us test the operational assumptions, and security is a launch gate.
